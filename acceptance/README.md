# Acceptance evidence

Public templates live here. Real x1 evidence belongs in `acceptance/private/`,
which is ignored because it may reveal addresses, usernames or indexer details.

An acceptance report must not include credentials, API tokens, provider account
identifiers or private indexer details.

`local-beta-report.md` records the current non-release local evidence and the
remaining blockers. It is deliberately separate from the x1 acceptance report.
