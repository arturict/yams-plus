# Security policy

## Supported versions

YAMS Plus is currently an early beta. Only the latest commit on `main` receives
security fixes; no released version is supported yet.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** form in the repository Security tab.
Please do not open a public issue for a vulnerability or include credentials,
private network details, provider account data or a working exploit against a
real host.

Include the affected commit, impact, prerequisites and the smallest safe
reproduction you can provide. You should receive an acknowledgement within
seven days. No bug-bounty programme is currently offered.

For ordinary hardening ideas that do not disclose an exploitable weakness,
open a regular GitHub issue.
